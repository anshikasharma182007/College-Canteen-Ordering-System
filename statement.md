1. Problem Statement:
   College canteens often require a simple and organized way to manage food orders and calculate bills. This project provides a basic system that allows users to select food items, enter quantities, calculate the total amount and receive an order summary.
2. Scope:
   It covers food menu display, food selection, quantity input, multiple item ordering, bill calculation, discount calculation and generation of final order summary
3. Target Users:
   It is intended for college canteen customers and canteen staff who need a simple way to manage food orders and billing.
4. Features:
   1. Display available food items and prices
   2. Select food items from the menu
   3. Enter required quantity
   4. Add multiple food items to one order
   5. Calculate the subtotal
   6. Apply discounts based on the bill amount
   7. Generate an order summary
   8. Handle invalid user inputs
