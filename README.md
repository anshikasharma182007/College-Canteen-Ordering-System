# College-Canteen-Ordering-System
The College Canteen Food Ordering System is a Python-based project that allows users to view the food menu, select food items and quantities, calculate the total bill, apply discounts, and generate an order summary through a simple command-line interface.
The project is divided in multiple python modules such as menu.py, order.py, billing.py and summary.py. This modular structure makes the program easier to understandd, test and maintain.

Features-
1. Display food menu
2. Place food orders
3. Select quantity
4. Calculate bill
5. Apply disocunts
6. Generate order summary
7. Handle invalid inputs

Technologies Used
1. Python
2. Python modules

How to run
1. Download or clone the repository.
2. Open the project folder in a terminal.
3. Run- python main.py

Instructions for testing
1. Open command prompt or terminal.
2. Navigate to the project folder.
3. Run the program using main.py
4. Select 1 to check whether the menu is displayed correctly.
5. Select 2 to place an order.
6. Enter a valid food item number and quantity.
7. Add multiple food items and check whether the order summary displays all selected items correctly.
8. Check whether the subtotal, discount, discount amount and final amount are calculated correctly.
9. Enter an invalid food item number and check that an error message is displayed.
10. Enter an invalid quantity such as 0 or a negative integer and check that the program asks for a valiud quantity.
11. Enter letters instead of numbers where numbers are required and check that the program handles the invalid input without crashing.
12. Select 3 to check whether the program exits correctly.
